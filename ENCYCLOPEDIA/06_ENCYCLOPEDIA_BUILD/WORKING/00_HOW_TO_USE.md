# Как пользоваться рабочей энциклопедией

## Кому это

ИИ и человеку, которым нужно объяснить **ванильный WorldBox этой сборки**, а не устройство каждого класса.

## Уровни доступа

Каждая важная механика относится ровно к одному уровню. Если путей несколько — они перечисляются отдельно.

### VANILLA

Обычная игра: вкладки HUD сцены `level1`, inspect, редакторы meta-окон, законы мира, хоткеи паузы/скрытия UI.

Пример: вкладка Destruction → `madness` вешает trait `madness` на юнитов в радиусе.

### DEBUG

Встроено в ванильную игру, но открывается только после разблокировки Debug Menu (11 кликов GraphyCaller) или всегда доступная консоль `~` (это **лог**, не командный чит).

Не выдавать debug за обычный HUD.

### INTERNAL

Есть в коде и крутит симуляцию. У игрока нет кнопки.

Пример: `CityBehCheckCitizenTasks` назначает CitizenJob. `initDebugHotkeys()` нигде не вызывается.

### MOD_ONLY

Только моды этой копии (PowerBox, NeoModLoader, ModernBox, RulerBox, TPI). Вкладки модов **нет** в поставляемом `level1`.

Примеры PowerBox: создать армию, convert city, EditResources, duplicate culture. Это не ваниль.

## Метки фактов

| Метка | Значение |
|---|---|
| **CONFIRMED** | Цепь проверена кодом и (для UI) сценой/prefab исследованиями `05` |
| **PARTIALLY CONFIRMED** | Часть цепи закрыта |
| **REQUIRES LIVE VALIDATION** | Код ясен, живой клик в этом проекте не делали |
| **OPEN QUESTION** | Не закрыто; не выдумывать |
| **NEGATIVE CANON** | Системы нет (Expeditions) |

`04_UNIFIED_ENCYCLOPEDIA` мог писать NOT_CLOSED на War/UI. Для рабочей энциклопедии приоритет у более поздних документов `05_PLAYER_RESEARCH`, если они прямо проверяли вопрос.

## Чего здесь нет

Не исследуются заново: Housing, Happiness как отдельный контур, полный каталог Decision id, Biomes целиком, Boats/Docks, формулы mass/stamina/XP. Они в `OPEN_RESEARCH_GAPS.md`.

Промо MoonBox / Steam / реклама — ванильный UI, не симуляция.
